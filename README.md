# Thursday 19 November 2026 — the world's news in one image

A single 1024×1024 front page, "The World in One Day", summing up Thursday 19 November 2026: GTA VI's global rollout leads, with Anthropic's record $81.3bn IPO, Hakeem Jeffries' historic Speaker nomination, Voyager 1's one-light-day milestone and the Gaza ground operation below it, plus eight more stories, a 24-item world brief, a story map, a UTC timeline and a day-in-numbers box. The page is built as `frontpage.html` (inline SVG art, no external resources) and rendered to `entry.png` with headless Chromium.

Run it with Node 22: `MAKEFUN_OUTPUT_DIR=out node main.ts` — it copies `entry.png` into the output directory and prints a one-line summary.
