# Thursday 19 November 2026 — the world's news in one image

One 1024×1024 newspaper front page summing up Thursday 19 November 2026 in 33 numbered stories from every continent, each with its place, beat and source. The first three-way summit of Trump, Xi and Putin in Shenzhen leads the page, alongside the World Court's genocide ruling against Myanmar, the launch of GTA VI after 13 years and Anthropic's record Nasdaq IPO. A red date-check box lists the nearby stories deliberately left out as belonging to 18 or 20 November, so the page claims only what happened or was first reported on the day itself.

Run it with `node main.ts` — the program copies `entry.png` (rendered from `frontpage.html`) into the directory named by `MAKEFUN_OUTPUT_DIR`, or `/output` when that variable is unset, and prints one summary line.
